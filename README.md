# Café Ciel — Restaurant Website

Website for Café Ciel: a static single-page site plus a WordPress page-template port of the same design.

## Contents

- `index.html` — standalone static version of the site
- `template-cafeciel.php` — WordPress page template port
- `assets/` — images, menu PDFs, hero/background videos (desktop + mobile), and the Ambit font family

## Usage

**Static:** open `index.html` directly or serve the directory with any static file server.

**WordPress:** copy `template-cafeciel.php` into the active theme, upload `assets/`, and assign the "Café Ciel" template to a page.
